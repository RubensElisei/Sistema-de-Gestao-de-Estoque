# Sistema de Gestão de Estoque

Sistema de Gestão de Estoque com Interface Gráfica [Python]

Este projeto implementa um sistema completo para controle de mercadorias, permitindo o gerenciamento de entradas e saídas de produtos. 
A aplicação conta com uma interface desenvolvida em Tkinter.

O sistema permite:
Adicionar: Cadastro de novos produtos ou atualização de quantidades existentes.
Remover: Saída de mercadorias com verificação de disponibilidade em estoque.
Listar: Visualização formatada de todos os itens armazenados.
Buscar: Consulta rápida por nome para verificar a quantidade de um item específico.
